# AWS Portfolio Workshop — Student Starter

This is a four-page responsive portfolio inspired by the idea of a personal website, but with a different blue/mint design.

## What to edit during the workshop
1. Open `index.html` and find `TODO` comments. Replace your name, headline, and introduction.
2. Open `about.html`, `experience.html`, and `contact.html`. Replace placeholder content you want to personalize.
3. Optional: Change the color variables at the top of `style.css`.
4. Optional: Create a `favicon.png` and add `<link rel="icon" type="image/png" href="favicon.png">` inside the `<head>` of **each** HTML file.
5. Preview locally by opening `index.html` in your browser.

## Deploy to AWS Amplify
1. Make sure your website works locally.
2. Select the HTML files, `style.css`, and any images **inside this folder**. Compress the selected files to a NEW ZIP; `index.html` must be at the ZIP root.
3. In AWS Amplify, choose manual deployment / Deploy without Git and upload the new ZIP.
4. Open your generated HTTPS URL and test all pages.

**Important:** Don't upload this original starter ZIP directly. Customize and create your own deployment ZIP. AWS usage may incur charges; check your account's pricing and free-tier eligibility.
